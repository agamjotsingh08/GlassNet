# GlassNet glossary

| Term | Simple definition | Technical definition |
|---|---|---|
| First party | The site you chose to visit | The registered domain of the scanned page |
| Third party | Another service contacted by that site | A different registered domain receiving a request |
| Tracker | A service that may observe activity | A classified analytics, advertising, or behavior service |
| Cookie | Small browser memory for a website | A browser key/value record; GlassNet stores metadata only |
| Local storage | Browser memory that can remain after closing a tab | Origin-scoped Web Storage |
| Session storage | Browser memory for one tab session | Tab-scoped Web Storage |
| CSP | A site rule about allowed resources | Content Security Policy HTTP header |
| Consent manager | A tool for privacy choices | Software that displays and stores consent choices |
| Fingerprinting | Recognizing a browser by characteristics | Combining browser/device signals for identification |
| Registered domain | Main domain name | eTLD+1, such as example.co.uk |
| Redirect | A page sends you elsewhere | HTTP or browser navigation to another URL |
| Iframe | A webpage inside another page | An embedded browsing context |
| Service worker | Background browser helper | Script controlling caching and network behavior |
